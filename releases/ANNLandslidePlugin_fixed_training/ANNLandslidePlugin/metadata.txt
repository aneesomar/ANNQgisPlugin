about=This plugin provides comprehensive landslide susceptibility mapping using Artificial Neural Networks (ANN). Major Features: (1) **ADVANCED THRESHOLD OPTIMIZATION** - 5 comprehensive optimization methods (ROC, Precision-Recall, Landslide-focused, Cost-sensitive, F-beta), (2) **MODEL CALIBRATION** - Platt scaling for improved probability estimates, (3) **Spatial Cross-Validation** - Prevents data leakage with K-means spatial blocking and buffer zones, (4) **Advanced Model Architecture** - Attention mechanisms, residual blocks, and skip connections, (5) **Ensemble Feature Selection** - Combines SelectKBest, Random Forest importance, and RFE with voting, (6) **Edge Artifact Correction** - Distance-based dampening for border pixels, (7) **Optimized Training** - FocalLoss for imbalanced data, mixed precision, gradient clipping, early stopping, (8) **Memory Management** - Chunk-based processing with garbage collection for large rasters, (9) **Smart Threshold Selection** - Automatically finds optimal decision boundaries with 94.7% landslide detection rate, (10) **One-hot Encoding** - Proper categorical feature handling for Lithology (10 categories) and Soil (5 categories), (11) **NoData Filtering** - Robust handling of invalid extreme values, (12) **RobustScaler** - Better handling of outliers in geospatial data. The plugin now includes state-of-the-art threshold optimization for maximum real-world effectiveness.
