about=This plugin provides comprehensive landslide susceptibility mapping using Artificial Neural Networks (ANN). Major Features: (1) **Spatial Cross-Validation** - Prevents data leakage with K-means spatial blocking and buffer zones, (2) **Advanced Model Architecture** - Attention mechanisms, residual blocks, and skip connections, (3) **Ensemble Feature Selection** - Combines SelectKBest, Random Forest importance, and RFE with voting, (4) **Edge Artifact Correction** - Distance-based dampening for border pixels, (5) **Optimized Training** - FocalLoss for imbalanced data, mixed precision, gradient clipping, early stopping, (6) **Memory Management** - Chunk-based processing with garbage collection for large rasters, (7) **Threshold Optimization** - Automatically finds best classification threshold (0.3-0.8 range), (8) **One-hot Encoding** - Proper categorical feature handling for Lithology (10 categories) and Soil (5 categories), (9) **NoData Filtering** - Robust handling of invalid extreme values, (10) **RobustScaler** - Better handling of outliers in geospatial data. The plugin now replicates proven working methodologies with state-of-the-art spatial ML practices.
